## 落地步骤

1. **`store.py`**:`data/curation/{date}.yaml` 结构 `{event_id: {action: keep|drop|promote|demote, title, details, reason}}`;读写幂等,支持按 event_id 或标题定位
2. **模糊匹配**:标题 bigram Jaccard 相似度(复用 cluster 的相似度函数或独立实现)匹配 event_id,阈值 ~0.8,输出匹配列表供确认
3. **`apply.py`**:接收 DailyReport → drop 剔除条目、promote 把条目移入头条栏目、title/details 覆盖;返回修改后的 report + 变更摘要
4. **接线**:run_daily 出报落盘后,若 `data/curation/{date}.yaml` 存在则应用并重写 daily JSON + HTML + 触发 PDF 重渲染(best-effort);覆盖后的分析版本回写指纹缓存(避免重跑时被覆盖回退)
5. **CLI**:交互模式用 input 逐条选择;非交互模式参数化;`list` 显示当日已生效规则
6. **测试**(≥6 个):drop 后 JSON 不含该条、promote 进头条、fix-title 三处一致(JSON/HTML/导出)、模糊匹配命中、YAML 语法错误有明确报错不阻断主报、回写缓存不覆盖
7. **commit**:`feat(T11-C1): 人工编排覆盖`
