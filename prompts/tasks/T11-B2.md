## 落地步骤

1. **`charts.py` 纯函数**:`bar_svg(data: list[tuple[label, value]], ...)` / `line_svg(series: list[list[float]], labels, colors)` / `donut_svg(parts: list[tuple[label, value, color]])` → 返回内联 `<svg>` 字符串;全部参数化,不做任何 IO
2. **数据来源**:话题热度用 `storage.trend.topic_heat`;公司活跃用 `storage.company.top_companies`(T11-B1);运行健康用 `report_store.all_runlogs()`;缓存命中率用 runlog 的 cache 字段
3. **SVG 质量**:宽高自适应(viewBox)、刻度与文字不重叠、颜色区分同时配图例文字、数据为空显示空态文案(不空白不报错)
4. **XSS 安全**:所有 label/数值经 HTML/XML 转义后再拼 SVG(防注入)
5. **接入 server.py**:首页与健康页插入图表块;不引入任何外部 JS/CSS 请求(单 HTML 响应)
6. **测试**(≥5 个):SVG 含 `<svg>`、元素计数、空数据空态、转义(注入字符串被转义)、极值(0/负数/大数)
