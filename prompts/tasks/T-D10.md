## 落地步骤

1. **`anomaly.py`** 基于 T-C7 SQLite 索引做异常检测:
   - `check_company_spike(name, threshold=4)`:单日事件数 > N 倍周均
   - `check_topic_drop(category, days=3)`:连续 N 天 0 条
   - `check_collection_drop(threshold=0.5)`:今日采集量 < 昨日 X%
   - `check_all(rules)`:跑全部规则,产出告警列表
2. **`watch.yaml`**:规则配置(可热加载)
3. **`notifier.py`**:
   - macOS:`osascript -e 'display notification "..." with title "..."'`
   - Linux:`notify-send "..."`
   - Windows:`msg * "..."`(可选)
   - 邮件:直接 SMTP(可选)
4. **`alert.py` 改造**:加 `send_local_notification()` 通道
5. **CLI**:`python main.py watch [--dry-run] [--config data/watch.yaml]`
6. **`pipeline.py` 改造**:在采集/聚合阶段后调用 `anomaly.check_all()`,命中 → 调 `notifier.send()`
7. **测试**(≥5 个):
   - 模拟 1 周日报数据 → `watch --dry-run` 输出所有命中规则
   - 钉钉 webhook mock → 真告警可达
   - macOS 本地通知 mock → osascript 调用
   - 各规则单元测试
   - 配置加载失败 fallback 到默认规则
8. **commit**:`feat(T-D10): anomaly detection + watch`
