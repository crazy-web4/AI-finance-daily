## 落地步骤

1. **`brief.py` 生成逻辑**(纯模板,不依赖 LLM 也能出):
   - 头条:取 headline 栏目 Top3(标题 + details 首句截断)
   - 每栏目:取该栏目 importance 最高条目的标题 + 一句话(截断 ~60 字)
   - 关键数字表:遍历 items 的 key_data 字段(如 融资 $XB / 参数 XB),去重汇总
   - 全文链接:指向当日 `daily_{date}.html` / PDF 相对路径
2. **可选 LLM 润色**:若 LLM 可用,生成一段 150 字总括段(失败则模板拼接兜底,标记 quality_flags 无需)
3. **输出**:Markdown(标准 GFM) + HTML(内联样式,无外链) + PDF(复用 PDFRenderer,1-2 页,失败降级 HTML/MD)
4. **接线**:run_daily post_report_steps 自动产出 brief 三件套;`main.py brief --date` 可单独生成
5. **测试**(≥5 个):由合成 daily JSON 生成 brief、字数 300-400 且栏目全覆盖、LLM 不可用降级仍出、关键数字与全量版一致(抽检 key_data)、空栏目跳过不报错
6. **commit**:`feat(T11-D1): 3分钟简报版`
